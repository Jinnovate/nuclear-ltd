# Nuclear Ltd

The first public-facing foundation for [nuclearltd.com](https://nuclearltd.com): an evidence-led nuclear energy advocacy and education project.

## Run locally

Open `dist/index.html` in a browser. The site is intentionally dependency-free so it can be hosted on any static platform.

## Current scope

- Responsive one-page introduction
- Nuclear energy evidence snapshot
- Myth-busting previews
- Clear editorial principles
- Accessible mobile navigation
